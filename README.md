# KAI — Independent IT Consultant

フリーランスITコンサルタント向けのポートフォリオサイト。React・TypeScriptで実装しています。

## ローカルで表示

Node.js 24 / npm 11で動作確認済みです。

```bash
npm ci
npm start
```

ブラウザーで http://localhost:3000 を開いてください。バックエンドや認証情報は不要です。

## 本番ビルド

```bash
npm run build
```

生成先は `build/` です。自動テストはまだ登録されていません。

## 機能

- レスポンシブレイアウトと抽象グラフィックのアニメーション
- アプローチのカテゴリ絞り込み、詳細モーダル
- スマートフォン用メニュー
- 相談内容のクリップボードへのコピー（メール送信・データ保存はしません）
- キーボード操作と動きを抑える設定への対応

## 公開前の編集

`src/App.tsx` の氏名・プロフィール・事例を本人の情報に差し替えてください。現在の KAI は仮プロフィール、掲載事例はコンセプト事例です。問い合わせ先も未設定のため、相談フォームは下書きコピー用です。

色・レイアウトは `src/index.css`、ページタイトルと説明は `public/index.html` で編集できます。フォントは Google Fonts を使用し、取得できない場合はシステムフォントで表示します。
